# راهنمای استفاده از API سایت sms.ir

این مخزن، مستندات API سایت [sms.ir](https://sms.ir) را به‌صورت سلسله‌مراتبی و دسته‌بندی‌شده در اختیار توسعه‌دهندگان قرار می‌دهد.

> **این یک پروژه‌ی مستقل و غیررسمی است.** نویسنده‌ی این مستند وابسته به sms.ir نیست؛ محتوا از راهنمای پنل sms.ir استخراج، بازنویسی و سلسله‌مراتبی شده تا استفاده از آن — از جمله در ابزارهای هوش مصنوعی — ساده‌تر باشد. برای مرجع رسمی همیشه به [پنل و مستندات خود sms.ir](https://sms.ir) نیز مراجعه کنید.

## نکاتی که در مستندات رسمی نیامده

- **متد اعتبار، تعداد پیامک را برمی‌گرداند نه مبلغ ریالی.** متد `GET /v1/credit` با وجود نام‌گذاری «اعتبار»، در عمل تعداد پیامک باقی‌مانده‌ی حساب را برمی‌گرداند؛ جزئیات در [بخش ۵.۱](05-settings/01-credit.md).
- **معنای مقادیر آرایه `MessageIds`.** مقدار `0` یعنی شماره در لیست سیاه است و `null` یعنی شماره نامعتبر یا متن بیش‌ازحد بلند است؛ جزئیات در [بخش ۳.۱](03-sends/01-bulk.md) و [۳.۲](03-sends/02-like-to-like.md).

## نسخه‌ی تک‌فایلی

اگر می‌خواهید کل مستند را در یک فایل واحد داشته باشید (مثلاً برای بارگذاری در یک چت هوش‌مصنوعی یا جست‌وجوی سریع)، فایل [smsir-full.md](smsir-full.md) شامل تمام محتوای بالا به‌صورت یک‌جا و با فهرست مطالب داخلی است.

## اطلاعات کلی

- **آدرس پایه API:** `https://api.sms.ir/v1`
- **احراز هویت:** ارسال کلید خصوصی (API Key) در هدر `X-API-KEY` — جزئیات در [بخش ۱.۵](01-introduction.md)
- **فرمت خروجی:** JSON یا XML، قابل تنظیم با هدر `ACCEPT`
- **واحد زمان:** Unix Time بر حسب UTC
