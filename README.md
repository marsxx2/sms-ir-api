# مستندات غیررسمی API سایت sms.ir + Claude Skill

راهنمای کامل، سلسله‌مراتبی و به‌روز API وب‌سرویس [sms.ir](https://sms.ir) (یک سرویس ایرانی ارسال پیامک/OTP)، به‌همراه یک [Claude Skill](https://www.anthropic.com/news/skills) آماده برای استفاده در دستیارهای هوش‌مصنوعی.

## چرا این مخزن؟

سایت sms.ir راهنمای API خودش را فقط به‌صورت یک صفحه‌ی وب در پنل کاربری منتشر کرده و هیچ فایل قابل‌دانلود یا ماشین‌خوانی (Markdown، OpenAPI و ...) ارائه نمی‌دهد. این یعنی نمی‌شود آن را مستقیماً به یک ابزار هوش‌مصنوعی داد یا در یک ریپازیتوری کد نگه داشت. من (یک توسعه‌دهنده، بدون وابستگی به sms.ir) برای پروژه‌ی خودم این محتوا را استخراج، بازنویسی، سلسله‌مراتبی و تکمیل کردم و اکنون آن را برای استفاده‌ی سایر برنامه‌نویسان منتشر می‌کنم.

> **این پروژه رسمی و وابسته به sms.ir نیست.** برای مرجع رسمی و به‌روزترین اطلاعات (به‌خصوص قیمت‌ها، محدودیت‌های حساب و تغییرات آینده‌ی API) همیشه به پنل و پشتیبانی خود sms.ir مراجعه کنید. اگر تناقضی بین این مستند و رفتار واقعی API دیدید، لطفاً از طریق Issues گزارش دهید.

## ساختار مخزن

```
.
├── docs/          مستندات کامل و انسانی‌خوان API، به‌صورت سلسله‌مراتبی
│   ├── 01-introduction.md ... 06-status-code-tables.md
│   ├── 07-sdks/            مستند جداگانه برای هر یک از ۵ پکیج رسمی
│   ├── smsir-full.md       همان مستندات در یک فایل واحد (برای پیست در چت AI یا جست‌وجوی سریع)
│   └── README.md           فهرست مطالب و نکات کلیدی
│
├── skill/
│   └── sms-ir-api/         یک Claude Skill آماده‌ی نصب
│       ├── SKILL.md         دستورالعمل و مرجع فشرده برای Claude
│       └── references/      نسخه‌ی خودکفای مستندات (برای وقتی skill جدا از این مخزن استفاده می‌شود)
│
└── scripts/
    └── package_skill.py    بسته‌بندی پوشه‌ی skill به یک فایل .skill قابل‌نصب
```

**تفاوت `docs/` و `skill/references/`:** پوشه `docs/` مرجع اصلی و قابل‌مرور برای انسان‌هاست (در گیت‌هاب زیبا رندر می‌شود، لینک‌های داخلی نسبی دارد). `skill/sms-ir-api/references/` یک کپی خودکفا از همان محتواست تا خود پوشه‌ی `skill/sms-ir-api/` مستقل از بقیه‌ی مخزن هم قابل‌نصب و استفاده باشد (چون Claude معمولاً یک skill را جدا از بقیه‌ی فایل‌های مخزن نصب می‌کند). اگر محتوای `docs/` را اصلاح کردید، `skill/sms-ir-api/references/` را هم به‌روز کنید تا دو نسخه از هم عقب نیفتند.

## استفاده از مستندات (`docs/`)

از [docs/README.md](docs/README.md) شروع کنید. اگر می‌خواهید همه‌چیز را یک‌جا به یک چت‌بات هوش‌مصنوعی بدهید (بدون نصب Skill)، کافی است محتوای [docs/smsir-full.md](docs/smsir-full.md) را کپی و در پیام اول خود پیست کنید.

## استفاده از Skill (`skill/sms-ir-api`)

این پوشه یک [Agent Skill](https://www.anthropic.com/news/skills) استاندارد است (فایل `SKILL.md` با frontmatter و پوشه‌ی `references/`). با نصب آن، Claude به‌طور خودکار هر وقت درباره‌ی sms.ir، ارسال پیامک، یا پیاده‌سازی OTP با این سرویس صحبت کنید، این مرجع را می‌خواند — از جمله نکاتی که در مستندات رسمی sms.ir نیامده (مثل اینکه متد اعتبار در واقع «تعداد پیامک باقی‌مانده» را برمی‌گرداند، نه مبلغ ریالی).

### نصب

- **برای Claude.ai / Claude Code / Claude Cowork:** پوشه‌ی `skill/sms-ir-api` را کپی کنید و طبق مستندات نصب Skill مربوط به همان محصول اضافه‌اش کنید ([docs.claude.com](https://docs.claude.com) را برای راهنمای به‌روز نصب Skill بررسی کنید، چون محل و روش نصب ممکن است بین محصولات مختلف Claude فرق داشته باشد).
- **بسته‌بندی به‌صورت فایل `.skill`:** یک فایل `.skill` در واقع فقط یک zip از پوشه‌ی skill است. با اسکریپت `package_skill.py` واقع در `scripts/` آن را بسازید:

  ```bash
  python3 scripts/package_skill.py skill/sms-ir-api
  # یا برای تعیین پوشه‌ی خروجی:
  python3 scripts/package_skill.py skill/sms-ir-api ./dist
  ```

  خروجی، فایل `sms-ir-api.skill` است که مستقیماً قابل نصب است.

### محدودیت شناخته‌شده

لینک‌های داخلی درون `SKILL.md` فرض می‌کنند این skill همراه پوشه‌ی `references/` خودش استفاده می‌شود (که در همین مخزن هست). اگر می‌خواهید skill را طوری شخصی‌سازی کنید که مستقیماً از `docs/` (به‌جای کپی داخل `references/`) بخواند، مسیرهای نسبی داخل `SKILL.md` و لینک‌های `references/sdks.md` را متناسب با محل جدید اصلاح کنید.

## مشارکت

اگر خطا یا کمبودی دیدید (چه در مستندات API، چه در Skill)، لطفاً Issue باز کنید یا Pull Request بفرستید. به‌خصوص اگر رفتار واقعی یک متد با آنچه اینجا نوشته شده فرق دارد (مثل نکته‌ی متد اعتبار)، این نوع بازخوردها بسیار ارزشمند است چون معمولاً در مستندات رسمی نیست.
